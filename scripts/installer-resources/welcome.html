Install IconCraft @VERSION@

This installer places IconCraft in your Applications folder. It does not change any macOS security settings and it does not grant permissions on your behalf.

One short step after installation

Open IconCraft when installation finishes. Finish setup will appear on first launch and walk you through:

  • checking whether macOS allows IconCraft to change protected apps;
  • opening Privacy & Security → App Management, if action is needed;
  • choosing whether the optional background helper should keep skins applied while IconCraft is closed; and
  • confirming which permissions IconCraft deliberately does not request, including Full Disk Access, Accessibility and Screen Recording.

IconCraft shows only statuses it can actually observe or test. Merely opening System Settings is never reported as a granted permission.
