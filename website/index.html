Trust

Safe by design, not by promise.

  • Reversible, always. Changes are journaled first; Restore is exact, per app or all at once.
  • Verified originals. Genuine manufacturer artwork is source-checked before it’s offered to you.
  • One honest permission. App Management, proven with a live test — nothing broader is ever requested.
  • Local only. No account, no telemetry. The only optional network call is a GitHub update check you can switch off.
  • Signed & notarised. Developer ID, hardened runtime, stapled ticket. Check it yourself: spctl --assess --type execute /Applications/IconCraft.app

FAQ

Questions

Is IconCraft really free?

Yes — free and open source under the MIT licence. No tiers, no ads, no account. An optional PayPal contribution supports development.

Will it break my apps?

No. Changes are journaled before they’re made and can be restored per app or all at once. The app underneath — its code and files — is never modified beyond its name and icon.

Why does it ask for App Management?

Changing another app’s icon or name means writing inside that app’s bundle, which macOS guards with App Management. IconCraft proves the permission with the same harmless write check a real change uses.

Which Macs does it run on?

Any Mac on macOS 12.3 or later — the download is a universal binary for Apple Silicon and Intel.

Will Gatekeeper complain?

No. Release builds are Developer ID signed, hardened and notarised by Apple. Double-click and it opens.

What about Windows and Linux?

Both versions are in active development and will be out soon. They’ll bring the same reversible icon and name customisation to Windows apps and Linux desktop entries. Star the GitHub repo to hear when they land.

Does IconCraft phone home?

No telemetry, no analytics, no account. The only optional network call is the update check against GitHub releases, which you can turn off in Settings.

An app update reverted my icon. Now what?

The background keeper notices and reapplies your skin, even with IconCraft closed. If it ever can’t, it tells you rather than failing quietly.
