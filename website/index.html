When every new app looks the same

Apps built with today’s AI tools and clone templates often arrive wearing a stock icon and a generic name, so your Dock fills with lookalikes. Meanwhile the genuine originals are still on your Mac — just not attached to the apps that need them. IconCraft hunts those originals down, checks where each one really came from, and puts them back. And if you’d rather give an app a look of your own, that’s two clicks instead.

Everything in one window

Original icons restored

The Originals Vault searches your Mac for genuine manufacturer artwork, verifies each icon’s source, and offers it first in the picker — no guessing, no web downloads.

Customise any icon

Borrow the icon of any installed app or drop in any image file. IconCraft fits and squircle-clips it so it looks native in the Dock and Launchpad — running apps included.

Rename apps safely

Give apps names you recognise. Every rename is journaled with the original kept, so restoring is exact — per app, or everything at once.

Default apps, one place New

Browser, email, PDF, images, movies, audio, text, source code, HTML, ZIP and calendar files — see what opens each today and switch it in one click, system-wide.

The keeper keeps it on

A tiny background keeper re-applies your skins if an app update or another tool reverts them — even while IconCraft is closed. Control it from the menu bar.

Organise 100+ apps

Instant search (⌘K), sort A–Z, Z–A or customised-first, group by status or folder, and replace icons in bulk. Your arrangement is remembered between launches.

A quick tour

Every app. One list. Real icons.

IconCraft lists every installed app with the icon it wears now and the original or custom icon ready to apply. Originals stream in as they’re verified. Got apps outside /Applications — in your home folder, Setapp, another drive? Add apps folder brings them in too.

Pick a look in seconds

The picker leads with the automatically discovered original, then every installed app’s icon as a donor grid — plus any image file you choose. It’s preview-only: nothing opens, nothing changes until you hit Replace.

Default apps, finally in one place

macOS scatters these choices across Finder Get Info panels and individual app menus. IconCraft gathers eleven of them — web browser, email, PDFs, images, video, audio, text, source code, HTML, ZIP archives and calendar files — with the current default and every candidate. Changes go through the same LaunchServices Finder uses; macOS may show its own confirmation, and IconCraft verifies the result before telling you it worked.

Sort it. Group it. Done.

A–Z for finding, Z–A for the newest, customised-first for reviewing your work. Group by status to see what’s still untouched, or by folder to see where things live. Headers lead every group, counts included — and IconCraft remembers your choice.

Starts how you like

Launch at login, start quietly in the menu bar, show or hide the Dock tile and menu bar icon (it never lets you hide both — there’s always a way back in), gentle notifications when a skin needs attention, and automatic update checks. Maintenance is one click: refresh the icon cache or open your data folder.

Safe by design

  • Reversible, always. Every icon and name change is journaled; Restore is per-app or all-at-once, and your settings survive reinstalls.
  • Honest permissions. IconCraft needs App Management to change other apps’ bundles, and proves it with the same harmless write check a real change uses. It does not ask for Full Disk Access, Accessibility or Screen Recording.
  • Verified, not promised. Originals are source-checked before they’re offered; default-app changes are re-read and confirmed before the app reports success.
  • Local only. Everything runs on your Mac. No account, no telemetry; the optional update check only talks to GitHub.
  • Signed & notarised. Developer ID signed with a hardened runtime and notarised by Apple, so Gatekeeper opens it without a murmur. Check any time: spctl --assess --type execute /Applications/IconCraft.app

Questions

Is IconCraft really free?

Yes — free and open source under the MIT licence, no tiers, no ads, no account. If it’s useful, an optional PayPal contribution supports development.

Will it break my apps?

No. Changes are journaled before they’re made and can be restored per app or all at once. Original artwork is verified before it’s offered, and default-app changes are confirmed by re-reading the system state.

Why does it ask for App Management?

Changing another app’s icon or name means writing inside that app’s bundle, which macOS guards with App Management permission. IconCraft tests it genuinely — the same harmless write check a real change performs — and is upfront about what it does and doesn’t need.

Which Macs does it run on?

Any Mac on macOS 12.3 or later. The download is a universal binary for Apple Silicon and Intel.

Is it signed? Will Gatekeeper complain?

Release builds are signed with a Developer ID, hardened, and notarised by Apple, then code-signed all the way down. Double-click and it opens — no “unidentified developer” detour.

Does IconCraft phone home?

No telemetry, no analytics, no account. The only optional network call is the update check against GitHub releases, which you can turn off in Settings.

An app update reverted my icon. Now what?

That’s the keeper’s job: the background agent notices and re-applies your skin, even with IconCraft closed, and can let you know it did. If it ever can’t, it says so rather than failing quietly.

How do you count downloads?

GitHub counts every release-asset download; the counter on this page reads those numbers live from the GitHub API. No tracking pixels here.
