Is IconCraft really free?

Yes — free and open source under the MIT licence. No tiers, no ads, no account. An optional PayPal contribution supports development.

Will it break my apps?

No. Changes are journaled before they’re made and restored exactly, per app or all at once. The app underneath is never modified beyond its name and icon.

Why does it ask for App Management?

Changing another app’s icon or name means writing inside that app’s bundle, which macOS guards with App Management. IconCraft proves it with the same harmless write check a real change uses — and never asks for Full Disk Access, Accessibility or Screen Recording.

Will Gatekeeper complain?

No. Release builds are Developer ID signed, hardened and notarised by Apple. Double-click and it opens.

What about Windows and Linux?

Both are in active development and will be out soon, with the same reversible icon and name customisation. Star the GitHub repo to hear when they land.

Does IconCraft phone home?

No telemetry, no analytics, no account. The only optional network call is the GitHub update check, which you can turn off.
