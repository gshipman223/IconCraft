IconCraft for Windows

This copy is not code-signed. Windows SmartScreen may ask the first
time you open a downloaded IconCraft.exe. Normal use does not need an
administrator password.

IconCraft changes shortcuts in your account (Start menu, desktop, and
shortcuts you pinned to the taskbar). It does not edit program files.
Store apps are listed and left read-only. Default apps are changed in
Windows Settings; IconCraft only opens that page.

See PLATFORMS.md for the full list of what works and what does not.
