# Code of Conduct

IconCraft follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be welcoming, be respectful, assume good faith, and keep discussion
focused on the work. Harassment, discrimination, and publishing others'
private information are not tolerated in any project space.

Report unacceptable behaviour privately to the maintainer via GitHub
(@gshipman223). Reports will be handled confidentially and in good faith.
